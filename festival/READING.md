## 箇所1：（時間切れになったときの処理）

```swift

    self.questionEndsAt = nil
    questionRemaining = 0
    choose("", timeout: true)
    return
}
```

**何をしているか：**
残り時間が0秒以下になったら、タイマーを止めて、時間切れとして回答を処理します。

**なぜこう書くのか：**
ifで残り時間を確認し、時間がなくなったら自動で回答を終了させるためです。

**もしこう書かなかったら：**
時間がなくなっても時間切れの処理が行われず、制限時間を過ぎても回答できてしまいます。

このコードがないと、練習モードをオンにしても練習用の操作が表示されず、時間制限も初期設定に戻りません。
