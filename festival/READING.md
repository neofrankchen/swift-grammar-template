## 箇所1：（例：品名を追加するボタンの処理）

```swift
if !timeout && id == round.answerID {
    streak += 1
    correctCount += 1
    score += StroopRound.pointsPerCorrect
    lastAnswerWasCorrect = true
    lastMissWasTimeout = false
    audio.play(.correct)
} else {
    streak = 0
    lastAnswerWasCorrect = false
    lastMissWasTimeout = timeout
    audio.play(timeout ? .timeout : .wrong)
}
```

**何をしているか：**
時間切れではなく、選んだ答えが正解なら、正解数を増やして10点を加えます。不正解や時間切れの場合は、連続正解数を0にして、それぞれの音を鳴らします。

**なぜこう書くのか：**
ifと`else`を使うと、正解の場合と、それ以外の場合の処理を分けられるからです。`!timeout`も確認することで、時間切れの回答には点数が入らないようにしています。

**もしこう書かなかったら：**
score += StroopRound.pointsPerCorrectを消すと、正解しても得点が増えなくなります。また、`streak = 0`を消すと、間違えても連続正解数が残ってしまいます。

## 箇所2：（見出し）

```swift
if on {
    showsPracticeTools = true
    testUsesTimer = false
    questionLimit = 30
}
```

**何をしているか：**
練習モードをオンにしたとき、練習用の操作を表示します。最初は時間制限をオフにし、制限時間の設定を30秒にします。
**なぜこう書くのか：**
if onを使って、練習モードをオンにしたときだけ設定するためです。最初は時間を気にせず練習できます。
**もしこう書かなかったら：**
このコードがないと、練習モードをオンにしても練習用の操作が表示されず、時間制限も初期設定に戻りません。
