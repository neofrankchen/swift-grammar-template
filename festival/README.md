## 何ができるアプリか（3行）
ネコと一緒に、さまざまなジャンルの2択クイズを楽しめます。
1プレイ10問・1問30秒で挑戦し、答えの解説を読んで学べます。
得点や回答時間を記録し、端末内のランキングで順位を確認できます。
